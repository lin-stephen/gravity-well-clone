#  ![gwell](<../manual/gwell.jpg>) Multiplayer Game

---

**The current version of Gravity Well does *not* support multiplayer mode. **We are currently working on the multiplayer communication and hope to release an update in the coming months. All registered users of Gravity Well 4.x will be eligible for a free update to the multiplayer version. In multiplayer mode, humans will be able to either team up or go head to head in intense battles. The infrastructure of Gravity Well 4.0 currently has the potential for up to 40 players in a game at once! As we continue development of the update, it will become more clear as to how many players it will be feasible to support over a given network connection. Gravity Well will use DirectPlay which supports Internet, LAN and modem play.

For information regarding the status of this update, or any other product news, visit our web site at http://www.softwareengineering.com.
