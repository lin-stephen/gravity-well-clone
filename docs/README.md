# Docs

Project documentation for the Gravity Well clone.

| Section | Contents |
|---------|----------|
| [adr/](adr/README.md) | Architecture decision records for the clone |
| [reference/](reference/README.md) | Source material about the original 1995 game: the archived manual, screenshots, and a digest of game mechanics |

## Where things go

- **`reference/`**: facts about the *original* game only. Keep our own design decisions out of it, so it stays a clean record of "what the original did".
- **`adr/`**: important technical decisions, their context, and consequences.
- Other design docs, specs and plans get their own sibling folders (e.g. `docs/design/`, `docs/plans/`) as the project grows.
